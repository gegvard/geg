DirectExcel 3.4.2-BATCH-20260720 (НОВАЯ ВЕРСИЯ)

Проверка что это не старое:
  Edit → Plugins → ищи "DirectExcel Batch 3.4"
  В BP: нода "Get DirectExcel Version" → должно вернуть 3.4.2-BATCH-20260720
  Output Log при старте: "DirectExcel loaded: 3.4.2-BATCH-20260720"

Установка:
1. ПОЛНОСТЬЮ удали YourProject/Plugins/DirectExcel
2. Распакуй этот zip → папка DirectExcel в YourProject/Plugins/
3. Удали Binaries и Intermediate если вдруг появятся
4. ПКМ по .uproject → Generate Visual Studio project files
5. Открой .sln → Rebuild Solution (ОБЯЗАТЕЛЬНО)
6. Запусти UE

Без Rebuild будет старый DLL — версия не появится.

=== БЫСТРЫЙ ЭКСПОРТ (3.4.2) ===
Раньше медленно из-за рефлексии на каждую строку + reserve на каждую строку (O(n^2)).
Теперь так:

  Create/Load Excel
    -> Get Active Sheet
    -> Write Struct Array (sheet, startRow=2, startColumn=1, Items = твой массив студентов)
    -> (payments/services если надо: ForEach + Write Variant At / Write Variant Map)
    -> Beautify For Export
    -> Save Excel   (ОДИН раз в самом конце)

Write Struct Array пишет ВЕСЬ массив за один вызов. Поля структуры идут
слева направо начиная с startColumn. Массивы/Map внутри (payments/services)
пропускаются — их пишешь отдельно.

Никаких Append Struct Fields / Make Variant / Map Add на каждую строку больше не нужно.
