DirectExcel 3.4.9-BATCH-20260721

Проверка версии:
  Нода "Get DirectExcel Version" → 3.4.9-BATCH-20260721

Установка:
1. ПОЛНОСТЬЮ удали YourProject/Plugins/DirectExcel
2. Распакуй zip → папка DirectExcel в YourProject/Plugins/
3. Удали Binaries и Intermediate если появятся
4. ПКМ по .uproject → Generate Visual Studio project files
5. Открой .sln → Rebuild Solution
6. Запусти UE

=== БЫСТРЫЙ ЭКСПОРТ ===
  Create/Load Excel
    -> Get Active Sheet
    -> Write Struct Array (sheet, startRow=2, startColumn=1, Items = массив)
    -> (payments/services при нужде: Write Variant At / Write Variant Map)
    -> Beautify For Export
    -> Save Excel Async   (не блокирует игру; результат по пину On Saved)

Write Struct Array — весь массив структур за один вызов.
Beautify For Export — быстрое оформление (даты, жирный заголовок, автофильтр,
автоширина); форматирование дат теперь O(1) на ячейку.
Save Excel Async — сериализация и запись файла в фоне.

Доп. ноды (DirectExcel|Diagnostics): Log Sheet Stats, Get Highest Row,
Get Highest Column, Get Non Empty Cell Count.
