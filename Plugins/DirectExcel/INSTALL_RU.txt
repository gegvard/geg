Установка:
1. ПОЛНОСТЬЮ удали YourProject/Plugins/DirectExcel

5. Открой .sln → Rebuild Solution
6. Запусти UE

=== ГЛАВНОЕ: сохранение без фриза ===
Замени ноду "Save Excel" на "Save Excel Async" (категория DirectExcel|Workbook).
У неё два выхода-пина: On Saved и On Failed (+ время в мс).
Сериализация xlsx и запись файла идут в фоне — игра не встаёт.
ВАЖНО: пока не пришёл On Saved/On Failed — не меняй этот Workbook.

  Get Active Sheet
    -> Write Struct Array (sheet, startRow=2, startColumn=1, Items = массив)
    -> Beautify For Export
    -> Save Excel Async  --> (On Saved) ...

=== Замеры на экране ===
Прямо в игре появляются жёлтые/зелёные надписи [PERF]:
  WriteStructArray: N rows x M cols in X ms
  SaveExcelAsync: X ms
Плюс нода "Log Sheet Stats" печатает объём данных.

Если всё ещё медленно — пришли числа с этих надписей.
